atc 0.3.0 (atc-testkit 0.10.2)

atc 0.3.0 settles the command-line conventions: one help format, global exit
codes and a common `--json` envelope across commands. atc-testkit 0.10.2
carries 0.10.1's `python -m atc_testkit.docs --exclude GLOB` and help-text and
metavar fixes.

## Breaking

- Exit codes of `close-out`, `onboard`, `classify` and `task new` change.
- Every `--json` result gains the common envelope.
- Deprecated, removed in atc 0.4.0: `worktree cleanup`, the positional project
  of `onboard` and `bootstrap add`, and `bootstrap sync`.

## Tasks

- ATC-0016: CLI conventions: help grouping and format, global exit codes and
  `--json`, naming consistency, the version-compatibility and deprecation rule.
- ATC-0017: `atc_testkit.docs --exclude GLOB`; atc-testkit 0.10.1.

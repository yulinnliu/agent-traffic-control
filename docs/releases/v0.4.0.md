atc 0.4.0 (atc-testkit 0.11.0)

atc 0.4.0 adds the task backlog (`atc task plan`, `start`, `rank`, `drop`),
records that the Owner runs `atc integrate` (except `--check`) and every push,
and lets the workspace root reuse an `atc verify` PASS. atc-testkit 0.11.0
adds the host-wide test worker budget: a worker-count flag is clamped to the
pool size and a wait past the limit stops with `WORKER_WAIT_TIMEOUT`.

## Breaking

- Removed, as deprecated in 0.3.0: `worktree cleanup` (use `worktree clean`),
  the positional project of `onboard` and `bootstrap add` (use
  `--project NAME`), and `bootstrap sync` (use `onboard --sync`). Each is now
  an argparse usage error.

## Tasks

- ATC-0018: atc-testkit host-wide worker budget and shared CPU and memory

- ATC-0019: the Owner runs integrate and push; the root reuses `atc verify`

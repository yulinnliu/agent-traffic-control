# Out of scope

Concepts that were built, tried or proposed in the private predecessors and
rejected. Each file records the decision, the reason and where the evidence
lives, so the question does not reopen without new evidence. An issue
proposing one of these is closed as not planned unless it brings an observed
failure the recorded reasoning does not cover.

Evidence citations name documents in the archived `hami-opc` and
`hami-workspace` repositories.
